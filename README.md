## i-Shop — boutique en ligne

**[Voir le site](https://ishop-tatiana.vercel.app)** · [Code source](https://github.com/Tatiana77-git/Shop)

Une boutique de vêtements de sport féminins : catalogue, page produit, panier et paiement simulé.

- Catalogue chargé depuis un fichier JSON avec Axios
- Routes dynamiques avec React Router (`/product/:id`)
- Panier partagé entre les composants grâce aux props, gardé dans `localStorage`
- Total et nombre d'articles calculés à partir du panier
- Affichage adapté aux petits écrans, déployé sur Vercel

*React · TypeScript · Vite · Axios · Docker*

## ISTALearning — application full stack *(bientôt en ligne)*

Une plateforme de tests de langues (4 langues, 6 niveaux) avec comptes utilisateurs, espace administrateur et paiement en ligne.

- Frontend React, API Node.js / Express, base PostgreSQL
- Authentification avec JWT dans un cookie et tokens révocables
- Paiement avec Stripe
- Lancement avec Docker Compose, déploiement sur un serveur VPS

*React · Node.js · Express · PostgreSQL · Stripe · Docker*

## Météo

Une application qui affiche la météo d'une ville en temps réel.

- On tape le nom d'une ville et on appuie sur Entrée
- Requête à l'API **OpenWeatherMap** avec `fetch` et `async / await`
- Affiche la ville, le pays, la température, la température ressentie, les conditions et les minimales / maximales
- Affiche la date du jour (jour, date, mois, année)

*HTML · CSS · JavaScript · API REST*

## Trips — agence de voyages

Une page d'agence de voyages avec un calculateur de prix.

- Effet « machine à écrire » qui fait défiler les destinations (Paris, Tokyo, Venise…)
- Fenêtre modale qui s'ouvre et se ferme avec une animation
- Calcul du prix d'un voyage selon la destination, l'hôtel, la nourriture, le nombre de jours, d'adultes et d'enfants (les enfants paient la moitié), avec une option en plus
- Message d'erreur avec la bibliothèque SweetAlert2

*HTML · CSS · JavaScript · SweetAlert2*

## Budget

Un calculateur pour partager un budget entre plusieurs personnes.

- Calcule la part de chaque personne
- Ajoute une réserve « fun money » de 20 % du budget
- Affiche le total par personne
- Vérifie les champs et affiche une erreur avec SweetAlert2

*HTML · CSS · JavaScript · SweetAlert2*
