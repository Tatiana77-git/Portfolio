ISTALearning

Une plateforme full stack de tests de langues : l'utilisateur choisit un test, crée un compte, paie en ligne et reçoit le lien de son test par e-mail.

4langues
6niveaux (A1 – C2)
24tests
9tables PostgreSQL
3services Docker

Architecture

FrontendReact · TypeScript
→
BackendAPI REST · Node.js · Express
→
Base de donnéesPostgreSQL

Services externes : Stripe (paiement) · Resend (e-mails)

Parcours utilisateur

  1. Choix de la langue et du niveau dans le catalogue
  2. Page détaillée du test avec sa description
  3. Inscription ou connexion
  4. Paiement sécurisé avec Stripe
  5. E-mail automatique avec le lien vers le test acheté
  6. Historique des achats dans l'espace client

Frontend

  • React et TypeScript avec Vite
  • React Router : catalogue par langue, page de chaque test
  • Requêtes avec fetch et cookie de session (credentials: "include")
  • Menu adapté selon le rôle : visiteur, client ou administrateur
  • Inscription, connexion, « Mot de passe oublié »
  • Espace client avec l'historique des achats
  • Bandeau de consentement aux cookies
  • Tests avec Vitest et Testing Library

Backend

  • API REST en Node.js, Express et TypeScript
  • Architecture en couches : routes → middlewares → controllers → models
  • JWT stocké dans un cookie, avec une table de tokens pour une vraie déconnexion
  • Middleware d'authentification (401) et middleware administrateur (403)
  • Réinitialisation du mot de passe avec un token temporaire valable 1 heure
  • Paiement Stripe et e-mail automatique avec Resend
  • Tests unitaires des middlewares et du service de tokens

Base de données

  • PostgreSQL, 9 tables : clients, produits, achats, paiements, résultats, tokens, historique…
  • Relation plusieurs-à-plusieurs entre achats et produits
  • Table de statuts commune aux achats, paiements et résultats
  • Schéma et données créés automatiquement par des scripts SQL au premier lancement

Docker et déploiement

  • Docker Compose : frontend, backend et base de données
  • Volume Docker pour garder les données
  • GitHub Actions : tests et build à chaque push
  • Déploiement sur un serveur VPS (OVH)

Ce que j'ai appris

  • Relier frontend et backend avec des cookies : configurer CORS et les requêtes pour que la session fonctionne entre deux ports.
  • Garder la base et le code synchronisés : versionner le schéma et les données pour que le projet démarre sur n'importe quel ordinateur.
  • Déployer une application complète : lancer les trois services avec Docker sur un serveur distant.
